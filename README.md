# Filedini 拡張スクリプト集

Filedini 用の Python スクリプト3本セットです。外部パッケージ（pip）には一切依存しません。

| ファイル | 内容 |
| --- | --- |
| `migemo_jump.py` | **どこでもジャンプ**: タブ / ブックマーク / フォルダ履歴を migemo 横断検索して移動（＋フォルダ内インクリメンタル検索も同梱） |
| `open_in_new_tab.py` | 選択中のフォルダやショートカット（.lnk）のリンク先を**新しいタブで開く** |
| `toast_helper.py` | 画面下部に表示する **OSD トースト / クリック可能な候補リスト**（上記2本が利用する共通ライブラリ） |

## 動作要件

- Windows 64bit
- Filedini に埋め込まれた Python 上で実行されます
- `migemo_jump.py` の初回実行時のみインターネット接続（migemo エンジンの自動取得。後述）

## インストール

1. 3ファイルを Filedini の `scripts` フォルダ（このフォルダ）にコピーします。
   `toast_helper.py` は他の2本から import されるため、**必ず同じフォルダ**に置いてください。
2. Filedini のスクリプト設定で、使いたい機能を登録してホットキーを割り当てます。

### 登録する関数（エントリポイント）

| スクリプトファイル | 関数名 | 機能 | ホットキー例 |
| --- | --- | --- | --- |
| `migemo_jump.py` | `migemo_jump` | どこでもジャンプ | `Ctrl+P` |
| `migemo_jump.py` | `migemo_isearch` | フォルダ内インクリメンタル検索 | `Shift+I` |
| `open_in_new_tab.py` | `open_in_new_tab` | 選択アイテムを新タブで開く | `Shift+Enter` |

`toast_helper.py` は登録不要です（ライブラリとして自動で読み込まれます）。

## migemo_jump.py

### migemo_jump — どこでもジャンプ

開いているタブ / ブックマーク / フォルダ履歴を、1つの migemo ピッカーで横断検索します
（VSCode の `Ctrl+P` のような体験）。ローマ字を打つたびに画面下部の **OSD リスト**が絞り込まれます。

| マーカー | ソース | 確定時の動作 |
| --- | --- | --- |
| `[T]` | 開いているタブ | そのタブに切り替え |
| `[B]` | ブックマーク（`config/Bookmark.json`） | 新しいタブで開く |
| `[H]` | フォルダ履歴（`config/History.json`・新しい順） | 新しいタブで開く |

- 同じパスが複数ソースにある場合は **T > B > H** の優先で1件に統合します。
  すでに開いているフォルダは重複タブを作らず、タブ切り替えになります。
- パスも検索対象なので、親フォルダ名しか覚えていなくてもヒットします。
- 本体の設定ファイルは**読み取りのみ**です（書き換えません）。ブックマークの編集は
  Filedini 本体で行えば、次回起動時のピッカーに自動反映されます。

#### 操作

| 操作 | 動作 |
| --- | --- |
| ローマ字を入力 | 入力のたびに候補リストを絞り込み（**移動はしません**。フォーカスも奪われません） |
| `Enter` / `Open` | 選択中の候補へジャンプ |
| 候補行をクリック | その候補へ即ジャンプ（ホバーでグレー表示） |
| `Prev` / `Next` | 選択行（青ハイライト）を循環移動 |
| `Escape` / `Cancel` | 何もせず閉じる（候補リストも消えます） |

候補が11件以上のときは選択行が中央に来るようスクロールし、`↑ 他 N 件` / `↓ 他 N 件` と表示します。

### migemo_isearch — フォルダ内インクリメンタル検索

現在のフォルダ内の項目を migemo で検索し、入力のたびに**最初のマッチへカーソルがライブ移動**します。
`Next` / `Prev` で候補を循環、`Close` で閉じます（カーソル位置はそのまま残ります）。

### セットアップ（migemo エンジンの自動取得）

migemo の検索には C/Migemo の `migemo.dll` と UTF-8 辞書が必要です。初回実行時に
**自動でダウンロード・展開**します。

1. 取得元: `https://files.kaoriya.net/goto/cmigemo_w64`（KaoriYa 配布の win64 zip へのリダイレクト）
2. 展開先: スクリプトと同じ階層の `migemo_runtime/`
   - `migemo_runtime/migemo.dll`
   - `migemo_runtime/dict/utf-8/migemo-dict`（＋ `roma2hira.dat` / `hira2kata.dat` / `han2zen.dat` / `zen2han.dat`）

> **重要**: `dict/utf-8/` 内の変換テーブル（`roma2hira.dat` 等）は、`migemo.dll` が辞書と同じ
> フォルダから自動読込します。これらが揃っていないと**ローマ字→ひらがな変換が無効**になります。

一度展開されれば、以降はダウンロードせず `migemo_runtime/` のファイルを使います。
オフライン環境へ導入する場合は、セットアップ済みの `migemo_runtime/` フォルダごとコピーしてください。

#### 自動取得に失敗する場合（手動配置）

1. C/Migemo の Windows 64bit 版を入手: <https://www.kaoriya.net/software/cmigemo/>
2. zip 内の以下を `scripts/migemo_runtime/` にコピー
   - `migemo.dll`
   - `dict/utf-8/`（フォルダごと。`migemo-dict` と各 `*.dat` を含む）

### ローマ字入力のコツ

C/Migemo 標準のローマ字解釈です。撥音「ん」の直後にナ行・ヤ行が続く語は `n` を重ねます。

- 「新入（しんにゅう）」→ `sinnnyuu`（n 3つ）。`sinnyuu` は「しんゆう（親友）」になります
- 「工数（こうすう）」→ `kousuu`（`kosuu` は「こすう（個数）」）

## open_in_new_tab.py

選択中のアイテム（未選択時はカーソル下）を種類に応じて新しいタブで開きます。
ショートカットだらけのランチャー用フォルダから、リンク先へサッと飛ぶための機能です。

| 選択アイテム | 動作 |
| --- | --- |
| フォルダ | そのフォルダを新しいタブで開く |
| `.lnk` → リンク先がフォルダ | リンク先フォルダを新しいタブで開く |
| `.lnk` → リンク先がファイル | リンク先の親フォルダを新しいタブで開き、そのファイルにカーソル |
| 通常ファイル / リンク切れ | スキップ |

- 複数選択に対応（一度に開くのは最大10タブ）
- `.lnk` の解決は `ctypes` による COM（`IShellLinkW`）直接呼び出しで、日本語パス・UNC パス対応

## toast_helper.py

画面下部中央に表示する軽量な OSD 通知ライブラリです。Win32 API（`ctypes`）のみで実装しており、
フォーカスを奪わず、通常のトーストはクリックも透過します。他のスクリプトからも利用できます。

```python
from toast_helper import show_toast, show_list_toast, dismiss_toast

# 単発トースト（1.5秒表示して自動フェードアウト。クリック透過）
show_toast("コピーしました（3件）")

# 選択行ハイライト付き候補リスト（on_click を渡すとクリック可能になる）
show_list_toast(
    ["候補A", "候補B", "候補C"],
    selected=1,
    duration_ms=8000,
    on_click=lambda row: print(f"row {row} clicked"),
)

# 表示中のトースト/リストを即座に閉じる
dismiss_toast()
```

- 呼び出しは即座に返ります（表示は別スレッド）。連続呼び出しは古い表示を置き換えます（常に1件）
- クリック可能リストはホバー行がグレー表示になり、マウスが乗っている間は自動で消えません
- `on_click` のコールバックは**トースト側のスレッド**から呼ばれる点にだけ注意してください
- 見た目の調整はファイル冒頭の定数で: `_FONT_HEIGHT`（既定 -14 ≒ 14px）、`_FONT_FACE`、
  `_BG_COLOR` / `_TEXT_COLOR` / `_HILITE_COLOR`、`_BOTTOM_MARGIN` など

## トラブルシューティング

- **一部の語しか日本語に展開されない**（例: `tokyo` は東京になるが `kanji` が漢字にならない）
  → `migemo_runtime/dict/utf-8/` に `roma2hira.dat` / `hira2kata.dat` が無い状態です。
  `dict/utf-8/` を丸ごと配置し直してください。
- **「Migemo Setup Failed」ダイアログが出る**
  → 自動ダウンロードに失敗しています。上記「手動配置」を行ってください。
- **「Migemo Load Failed」ダイアログが出る**
  → `migemo.dll`（64bit）の読み込みに失敗しています。配置場所と bit 数を確認してください。
- **候補リストが表示されない**
  → `toast_helper.py` が同じフォルダに無い可能性があります。配置を確認してください
  （無くても検索・確定は動作しますが、候補の表示が出ません）。
- **`.lnk` を選んでも開かない**
  → リンク切れ（リンク先が存在しない）か、ターゲットを持たない特殊なリンク
  （URL ショートカット等）です。スクリプトログに警告が出ます。
